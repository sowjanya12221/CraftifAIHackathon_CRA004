DeepStream Parsers

This folder contains C++ source files, header files, and build-support files used by the DeepStream pipeline.

Files

- "config-IFIN-DET-IFIN-PGIE-parser.cpp" — Parser source for the object-detection model.
- "event_sync.h" — Header file for event synchronization.
- "makefile" — Build instructions for the parser components.
- "pose_render_process.cpp" — Source file related to pose rendering and processing.
- "render_meta.h" — Header file for rendering metadata.
- "shape_json.h" — Header file for shape and JSON-related data.
- "VMS_detect.cpp" — Source file related to detection processing.

These files support processing and displaying the outputs of the object-detection and pose-estimation pipeline.
