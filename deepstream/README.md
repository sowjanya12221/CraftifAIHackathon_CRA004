DeepStream Pipeline

This folder contains configuration files, model parsers, and supporting scripts for the PipeGen object detection and pose estimation pipeline.

Contents

- "configs/" — Object detection and pose estimation configuration files.
- "labels/" — Object detection class labels.
- "parsers/" — C++ source files and supporting headers for processing detection and pose-estimation outputs.

The pipeline uses YOLOv8n for object detection and YOLO11n Pose for human pose estimation.
