YOLOv8n Object Detection

This folder contains files related to the YOLOv8n object-detection model used in the PipeGen perception pipeline.

Purpose

YOLOv8n detects objects in live webcam frames and produces bounding boxes and class labels.

Model

- Model: YOLOv8n
- Format: ONNX
- Task: Real-time object detection

The model is used as one branch of the parallel object-detection and pose-estimation pipeline.
